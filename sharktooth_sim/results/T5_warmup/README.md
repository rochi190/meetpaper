## 結論

1. **暖機讓 δT 前期彎曲**：22 → 34 °C、τ = 10 min 時，斜率前後差 +1.8 ppm，真 δT 偏離直線最多 1.2 ms。
2. **單一節點**（A8 = −248）：第 1–3 段誤差明顯變大（最差組合 0.50 / 0.39 / 0.21 ms，對照 0.25 / 0.12 / 0.09 ms），
   τ 越長、溫差越大越嚴重；第 5–6 段已回到對照水準。累積 OLS 在結束時的 α 誤差 0.58 ppm（對照 0.03）
   ——**彎曲確實被留在累加量裡，表現為斜率偏差**；在 1 小時內換算成時間誤差不大，但記錄越長、外插越遠越明顯。
   遺忘因子：λ = 0.9999（記憶約 1000 s）第 6 段 0.04 ms，與累積 OLS 相當；λ = 0.999（約 100 s）反而變差（0.15 ms，δT* 的雜訊漏進來）。
3. **節點對**（論文 RSE 量的東西）：大家一起升溫，ρ_temp 大部分抵消，第 1 段幾乎不變（0.33 vs 對照 0.32 ms）；
   但各節點升溫曲線不同時，**彎曲留在累積 OLS 裡造成的斜率偏差會讓第 5–6 段的節點對誤差變大**
   （22→34 °C、τ = 10 min：0.14 / 0.17 ms，對照 0.07 / 0.06 ms）。
   遺忘因子對節點對：λ = 0.9999 把這組第 5–6 段降到 0.12 / 0.11 ms（對照組則從 0.07 / 0.06 稍升到 0.09 / 0.08）；
   λ = 0.999 各段都在 0.24 ms 左右，太短。→ **溫度會變的長時間記錄，λ ≈ 0.9999 是合理折衷**。
   → 暖機**不能**解釋 Table II「第 1 段大、之後收斂」：它造成的是「後段慢慢變大」。第 1 段大主要是 SharkTooth 起始收斂（對照組第 1 段 0.32 vs 第 6 段 0.06 ms），見 T6。
4. **A8 的意外發現：大的正斜率對 SharkTooth 有利。** A8 = 0 時約 41 % 的節點 α < 0（δT 隨時間下降）：
   每個新低點都成為新樞紐點 → 迴歸矩陣歸零 → 論文字面版在 30 s 穩定期內輸出 α = β = 0（無效）。
   結果無效輸出 24 %（A8 = −248 時 0.9 %）、樞紐點 49 個（7 個），
   節點對誤差各段約 0.88 ms（A8 = −248 時約 0.08 ms）。詳見 T7e。
   論文三張圖的斜率都是 235–245 ppm（遠超 ±20 ppm 晶振）——**很像韌體共同的 tick 換算常數**（例如 1/32768 s 寫成 30.51 µs → −248 ppm），
   恰好讓所有節點 α 都 > 0，SharkTooth 才一直在「正常」模式下運作。換成換算正確的韌體，就會碰到負漂移問題。
