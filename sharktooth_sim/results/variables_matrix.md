# 模擬變因總表

模擬器考慮過的所有延遲／誤差來源，以及每個測試用了哪些。

- ID 對應 `docs/SharkTooth_模擬測試規格.md` 第 2 節。
- 設定鍵、預設值在 `sim/config.py` 的 `DEFAULTS`。
- 每個參數的出處與合理性在 [provenance_paper_match.md](provenance_paper_match.md)。

## 1. 變因清單與「和論文相符的設定」

「和論文相符的設定」= `config/T4_fig6.yaml` 加上 T4 擬合的 8 個參數（`results/T4_fig6/summary.json` 的 `best_params`）。
T5–T13 都以它為基礎。

## 3. 各測試改了什麼（◆ 的內容）

| 測試 | 目的 | 改的變因 |
|---|---|---|
| T1 Fig.3 | 最小延遲 | 單節點；斜率直接用 ρ = −245 ppm（不用 A8）；封包間隔 100.93 ms；關 C3、E2、C11；E1 掃 0.2–5 ms |
| T2 gcd | 相位鎖定、階梯 vs 平滑 | 以 T1 為基礎；CI 掃 30 / 31.25 / 37.5 / 45 / 50 ms；E1 掃 0.5 / 5 / 10 ms；封包計時器鎖晶振（245 ppm）vs 論文的 100.93 ms |
| T3 Fig.4 | 雜訊 | 以 T1 為基礎；ρ = −235 ppm、封包間隔 100.64 ms；開 C3（Gilbert–Elliott）與 E2，格點＋800 次隨機搜尋 |
| T4 Fig.6 | 主要目標，擬合 | 4 節點／1 dongle；A1 ±20 + A8 −248 ppm；封包間隔 100.78 ms；擬合 D2、E1、C3 四個參數、E2 發生率、C11 |
| T5 暖機 | 晶振暖機（早期版） | 2 節點；A2 + A3：T_start 22 / 25、T_end 30 / 34 °C、τ 2 / 5 / 10 min；A8 0 vs −248；遺忘因子 1 / 0.9999 / 0.999 |
| T6 Table II | 多節點、論文式 RSE | 18 個配置（2–12 節點 × 17 / 127 / 244 B）；C3 改成每個配置用 Fig.12 σ²100 校正的獨立失敗率；開 F（ADC 雜訊 ∝ 封包長度、AFE 延遲差）與 dongle 路徑差 0.1 ms |
| T7 完整性 | 資料錯誤 | 1 節點；逐一開：掉包 / 斷線 5 s / buffer 讀錯 / 重複封包 / 重開機 / 31-bit 溢位；完整性檢查、預傾斜 +100 ppm |
| T8 基準方法 | 和先前方法比較 | 4 節點與 12 節點（C3 好狀態 22.5 %）；「不同」情境讓節點 0 的 PER +20 %、韌體延遲最大 10 ms；10 種同步方法 |
| T9 敏感度 | SharkTooth 參數 | M、λ_max、γ1 增量、穩定期、keep_last 格點；封包率 5 / 10 / 20 Hz（f_s 100 Hz，20 Hz 時流量控制 window = 2） |
| T10 漂移來源 | 斜率是否自然產生 | 「論文設定」vs「只有物理誤差」（A8 = 0、PC ±50 ppm）；預傾斜 +100 ppm |
